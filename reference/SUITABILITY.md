# Reference suitability verdict — bench vise

Rubric: `grimoire/intake/validation_rubric.md`. Verdict: **PASS (conditional on rear inference)**.

| Criterion | Result | Evidence |
|---|---|---|
| one obvious target object | pass | single vise on an empty seamless backdrop, nothing else in frame |
| object occupies enough of the frame | pass | ≈80% of frame width, ≈70% of height |
| at least one strong silhouette | pass | near-orthographic side view; the full jaw/screw/base outline is unbroken against the backdrop |
| major materials visible | pass | bare ferrous metal in four machining states, all lit and readable |
| hidden side reasonably inferable | conditional | subject is bilaterally symmetric about the screw-axis plane, so the −Z half is mirrored from the observed +Z half — recorded as inference, not observation |
| approximable with procedural primitives | pass | extruded profiles, chamfered boxes, helical sweep, lathe/disc stack, spheres — no smoke, liquid, glass or lace |

Not rejected: the subject is not ambiguous, not a scene, no identity-defining shape is cropped or
blurred, and the request is for a procedural scene rather than mesh extraction or
manufacturing-grade dimensions.

Accepted stylizations, stated up front:
- jaw-plate serration pitch is approximated (reference pitch is below reliable count resolution);
- absolute scale is conventional (125 mm jaw width), since the reference carries no scale cue;
- the rear half, base underside, nut-boss interior and slide channel interior are reconstructed by
  symmetry/engineering convention and are not observed.
